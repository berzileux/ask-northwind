# ask-northwind

ask-northwind is a small public demo. A visitor asks a question in plain English about the Northwind sample database, a model writes one SQL statement, plain code validates it and runs it in a read-only sandbox, and the page shows the answer and the SQL that ran. It is not an agent: one model call, no tools, no retries. The code, not the prompt, enforces safety..

## Data

northwind.db is not generated by this project. Download it once into the repo root and verify it:

    curl -L -o northwind.db https://raw.githubusercontent.com/jpwhite3/northwind-SQLite3/main/dist/northwind.db
    sha256sum northwind.db

Expected SHA-256:

    2f4f5c68dfcd33ba27373eae48c7a4869800c68095ee0f9f0da494f83382a877

Size 24702976 bytes, SQLite 3 format. If the hash differs, do not use the file.

- The copy is larger than the classic Northwind: 16282 orders and 609283 order lines, against 830 and 2155.
- Table names such as "Order Details" contain a space and are quoted in SQL.
- The file is third-party sample data whose license this project has not verified, so check it before redistributing.

## Setup

Create the environment with Python 3.11 or newer (`python3.11 -m venv .venv`, or `uv venv --python 3.11`), then:

    pip install -r requirements.txt -r requirements-dev.txt

All dependencies are tracked in those files and nothing is installed any other way.

## Configuration

The only environment variable is GEMINI_API_KEY. The model name is a constant in model.py. Never commit a key; .env is in .gitignore.

## Tests

    python -m pytest -q

The tests use a generated database, need no key and make no network call. One test needs northwind.db and is skipped when it is missing. live_check.py is separate: it calls the real model and needs the key and northwind.db.

## Delivery

The image is built by Cloud Build from the Dockerfile and cloudbuild.yaml and served by Cloud Run in us-central1. The key is read from Secret Manager at run time. The web page and the deploy steps are added in later phases, and the image cannot run until then.

## Run locally

    .venv/bin/python -m uvicorn app:app --port 8080

Then open http://localhost:8080. The page makes real model calls, which use the free quota. The app refuses to start when northwind.db is missing. The health check path is /healthz.
